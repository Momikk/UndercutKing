## 0.1.0.17 顶部标签与选项可读性

2026-10-18：根据 0.1.0.16 的实机截图，将左侧按钮改为原生 TabBarNode 顶部六标签。内容改为整窗宽度，窗口为 760×560，六页与原有设置保持不变。移除重复页标题，腾出纵向空间。帮助按钮由 26×26 的问号改为 68×28 的「说明」，保留悬浮和点击后底部说明两种入口。

Release 构建 0 警告、0 错误。原生库独立检查 7 项及全部原有功能回归通过。仍需用户游戏内确认六标签切换、不同主题与缩放、长标签完整显示及「说明」按钮可见和可点击；没有连接或操作游戏进程。
