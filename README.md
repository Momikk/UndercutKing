# 压价之王 UndercutKing

轻量《最终幻想 XIV》Dalamud 市场辅助插件，帮助你发现被压价的雇员商品。

**当前版本为早期测试版（0.1.0.9）**，由 Momikk 开发和维护。插件提供价格提示，调整售价由你自行完成。

版本更新记录：[中文 Changelog](CHANGELOG.zh-CN.md) · [English Changelog](CHANGELOG.md)。插件管理器中的更新说明同时提供中文和英文。

## 当前功能

读取雇员当前上架商品的单价，同一物品合并 NQ / HQ 比较市场最低价，在游戏原生雇员销售列表和雇员列表中高亮提示。高亮提供自动、浅色界面、深色界面三套配色选择：浅色界面使用深红与深琥珀色，深色界面使用较亮的红色与黄色，搭配适合背景的描边；关闭高亮或卸载时恢复原来的颜色与描边。修改售价后重新读取价格并更新状态。

| 显示状态 | 含义 |
| --- | --- |
| 红色 | 你的单价高于同物品 NQ / HQ 两者中的市场最低价 |
| 黄色 | 报价未知、已过期或不足以确认价格状态 |
| 蓝色 | 普通背包四栏中也有同一物品，不区分 NQ/HQ；蓝色优先于红黄名称颜色 |
| 普通颜色 | 按当前有效报价，未检测到被压价 |

“背包同物品标蓝”默认开启，打开雇员出售列表或雇员总列表后每约 0.25 秒检查普通背包四栏，不包含兵装库、陆行鸟鞍囊或雇员背包。只要背包中有正数量的同物品就命中，无论品质或数量；出售列表中同物品的各上架位名称标蓝，总列表中有任一已扫描商品命中的雇员，其“出售中（件数）”市场文字标蓝。总列表按当前角色该雇员最近一次已保存的上架快照判断，未扫描的雇员无法确认命中。移出背包、关闭功能或卸载后恢复原有市场高亮或原始文字样式。蓝色优先于红黄文字颜色，压价数量和插件价格表仍按实际市场报价判断；此功能与市场红黄高亮开关独立，仅读取本地库存，不增加 Universalis 请求。

支持自动查询 Universalis，也会读取你手动打开“比较价格”后收到的完整游戏市场列表，优先使用有效的游戏内报价。Universalis 数据可能滞后，提示结果取决于已取得报价的完整性和新鲜度。

服务器信息栏显示当前角色已扫描雇员的被压价上架位数量，点击可以打开插件界面。相同物品的不同上架位分别计数。

雇员列表的市场栏在原有出售数量后追加各雇员的被压价上架位数量，例如“出售中（14件） (3)”。按有效报价未检测到被压价时不追加括号，`(N+)` 表示已确认 N 个且还有价格待确认的商品，`(?)` 表示未扫描或数量尚未确认。可通过“雇员列表显示各雇员压价数量”单独关闭计数；关闭列表高亮仍可保留计数。新增、撤回或售出的商品仍需重新扫描对应销售列表。

| 信息栏文字 | 含义 |
| --- | --- |
| `压价 N` | 已扫描商品中，确认有 N 个上架位被压价 |
| `压价 N+` | 已确认 N 个被压价上架位，另有商品价格待刷新 |
| `压价 ?` | 尚未取得足够数据，无法确认数量 |

## 安装方法

1. 在游戏聊天栏输入 `/xlsettings`，进入 **插件 → 第三方插件**。
2. 添加以下仓库链接，勾选启用并保存设置：

   ```text
   https://raw.githubusercontent.com/Momikk/DalamudPlugins/main/pluginmaster.json
   ```

3. 输入 `/xlplugins`，刷新插件列表，搜索 **压价之王** 或 **UndercutKing**。
4. 安装 **压价之王 UndercutKing** 并启用。

该链接是 [Momikk 的统一插件仓库](https://github.com/Momikk/DalamudPlugins)。后续更新可直接在 Dalamud 插件管理器中进行。

## 使用方法

首次使用时，依次召唤各雇员并打开销售列表，完成当前上架商品的扫描。若启用插件时雇员窗口已经打开，请退出雇员交互后重新召唤。尚未扫描的雇员不会纳入完整的价格判断。

输入 `/uking` 或 `/undercutking` 打开设置与价格界面。默认启用物品高亮、雇员列表高亮、服务器信息栏计数和 Universalis 自动查询，价格有效期默认为两天，旧版配置升级时也调整为两天。可以在界面中分别关闭这些功能，按天调整价格有效期（上限 30 天），或点击“设为两天”。这表示报价数据的有效期，不是物品上架时长；缺少报价仍按未知状态提示。

查看提示后，可手动打开游戏中的“比较价格”取得市场报价，再自行调整售价。点击“刷新已扫描雇员的市场价格”会重新查询已扫描商品的报价；新增、撤回或售出的商品，需要再次打开对应雇员的销售列表更新快照。

登录且启用“自动查询 Universalis 市场价格”时，即使雇员窗口和市场板关闭，插件也会在后台更新已扫描商品的市场状态与服务器信息栏数量。“接收市场变化推送”默认开启：订阅已扫描商品所在服务器的新增及下架消息，仅对相关物品合并安排完整报价查询，短时间重复消息不会逐条发送请求。同物品推送补查至少相隔 30 秒；推送是增量变化，不直接作为完整市场最低价。

首次连接与重连后补查已扫描商品，正常连接时默认每 15 分钟批量核对，可设置为 1–60 分钟；推送关闭或连接不可用时，按设置值与 5 分钟中的较短间隔继续查询。旧版默认 5 分钟设置升级为 15 分钟，其他自定义间隔保留。两天报价有效期仍独立，只决定旧报价何时失效标黄。退出角色或没有已扫描商品时关闭订阅；关闭自动查询也停止推送并清除待执行查询，已开始的请求可能仍会完成。

同服务器最多 50 种物品合并一次查询，收集约 5 秒后进入单一请求队列，批次间隔至少一秒。手动刷新也使用该队列和每物品 5 秒冷却。遇到 429 限流时全部查询暂停至少一分钟，优先遵守服务器更长的 Retry-After，连续失败逐步延长等待；同一失败批次最多尝试三次。普通失败也延后重试，不会高频重复请求；成功后仍保留其他批次和单物品的节流。设置窗口显示推送连接、队列数量、暂停时间和错误状态。

Universalis 是[玩家共同上传数据的网站](https://universalis.app/)，定时查询只能获取其已有报价，不能强制游戏市场更新；冷门物品可能仍有明显延迟。旧上传时间不会因重复查询变成最新时间；完整游戏报价也不会被更旧的 Universalis 数据覆盖。

| 操作 | 作用 |
| --- | --- |
| `/uking` 或 `/undercutking` | 打开或关闭插件界面 |
| 点击服务器信息栏的压价数量 | 打开插件界面 |
| “刷新已扫描雇员的市场价格”按钮 | 请求更新已扫描商品的市场报价 |
| 游戏内“比较价格” | 获取当前物品的游戏市场报价 |

## 界面预览

主界面上方提供高亮、信息栏计数、自动查询和价格有效期设置，下方列出当前雇员的上架商品，包括物品名称、我的单价、市场最低价，以及状态与报价来源。尚未取得报价时显示“暂无报价”或“待刷新”。

游戏原生雇员销售列表和雇员列表通过颜色提示价格状态，服务器信息栏提供压价数量入口。实机截图将在补充后展示于此。

## 适配与使用条件

需要已启用 Dalamud 的游戏环境。当前版本针对 **Dalamud API 15** 构建，使用国服 XIVLauncherCN 的开发程序集，并针对国服客户端进行静态签名检查。游戏内加载、改价后刷新和高亮恢复等交互仍待完整实机验收；其他区服尚未验证。

如果同时使用 Allagan Market，请先关闭其物品和雇员高亮，或禁用该插件，避免同时修改相同的游戏文本。压价之王是独立插件，Allagan Market 的配置不会自动迁移。

自动查询 Universalis 需要能够访问该服务。查询失败或数据过期时，黄色提示表示价格尚未确认。游戏或 Dalamud 更新后，请以插件管理器中的兼容状态为准。

普通用户通过插件管理器安装即可，无需自行编译。源码构建和检查说明见[开发文档](docs/development.md)。

## 问题反馈

遇到安装、价格判断、高亮或计数问题，请前往 [GitHub Issues](https://github.com/Momikk/UndercutKing/issues) 提交反馈。也欢迎提出功能建议。

请提供插件版本、游戏区服、Dalamud 版本、复现步骤和实际表现。价格问题请尽量附上物品名称、HQ / NQ、所在服务器、你的单价、游戏内比较价格的截图及查询时间；加载问题可附上 `/xllog` 中与 UndercutKing 相关的报错。上传前请遮挡角色名等个人信息。

## 项目声明

压价之王是免费、开源的社区第三方插件，与 SQUARE ENIX、盛趣游戏及《最终幻想 XIV》官方无附属关系。

插件仅提供价格提示，不自动改价、操作雇员或进行交易。它会保存已扫描雇员的当前上架快照，不提供销售历史、统计报表或 CSV 导出。报价可能滞后，调整售价前请自行确认市场行情。

当前版本仍处于早期测试阶段，使用第三方插件可能存在风险，请自行评估。
