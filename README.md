# 压价之王 UndercutKing

面向《最终幻想 XIV》雇员市场的 Dalamud 插件，帮助你发现被压价的商品和背包中的同类物品。

**当前版本为早期测试版（0.1.0.23）**。

[中文更新记录](CHANGELOG.zh-CN.md) · [English Changelog](CHANGELOG.md)

## 当前功能

- 忽略服装模特的展示非卖品，不查价、不计数、不高亮。更新或修改展示/出售状态后，请打开一次对应雇员的出售列表识别，确认状态会保存。

- 游戏原生设置窗口，顶部按市场数据、雇员提示、背包提示和后台限帧分类，鼠标悬停选项查看说明，无需额外说明按钮。

- 打开普通背包时，同物品若同时存在 NQ 和 HQ，会用蓝框标出两种品质的所有格子；无需召唤雇员，可单独关闭，移走其中一种品质后自动取消。

- 配合回收之王 0.1.0.1 或更新版本时，其粉色遮罩与 X 优先于背包蓝框；清单内物品不再叠加蓝框，移出清单或关闭粉色标记后恢复原来的蓝色提示。

- 游戏失去焦点时自动限帧，默认 20 帧，可在设置中调整（5–240 帧）或关闭；切回游戏后停止限帧。游戏和显卡原有的更低帧数限制仍会生效。

- 在雇员出售列表和雇员总列表中高亮提示：红色表示被压价，蓝色表示背包中有同物品，黄色表示报价待确认。优先级为 **红色 > 蓝色 > 黄色**，NQ/HQ 视为同一物品。
- 打开当前雇员出售列表时，同时高亮普通背包中的对应道具，方便查找；可单独关闭。
- 在雇员列表和服务器信息栏显示被压价的上架位数量，点击信息栏可打开插件窗口；`+` 或 `?` 表示还有价格尚未确认。
- 支持 Universalis 后台查询和市场变化推送，也会读取游戏内“比较价格”的报价；可调整刷新间隔、报价有效期和高亮配色。

首次使用请依次召唤各雇员，收到完整在售数据后会自动更新记录与压价数量，无需打开出售列表；数据未收齐时保留旧记录。新增、撤回或售出商品后，再次召唤对应雇员即可更新。输入 `/uking` 或 `/undercutking` 可开关窗口。

插件仅提供提示，售价由你手动调整。Universalis 数据可能滞后，改价前请确认市场行情。背包匹配只包含普通背包四栏，不包含兵装库、鞍囊或雇员背包。

## 安装方法

1. 输入 `/xlsettings`，进入 **插件 → 第三方插件**。
2. 添加以下库链，勾选启用并保存：

   ```text
   https://raw.githubusercontent.com/Momikk/DalamudPlugins/main/pluginmaster.json
   ```

3. 输入 `/xlplugins`，搜索 **压价之王** 或 **UndercutKing**，安装并启用。

## 适配与使用条件

需要已启用 Dalamud 的游戏环境。当前版本针对 **Dalamud API 15** 构建，使用国服 XIVLauncherCN 的开发程序集。

已通过编译和回归检查，高亮位置、背包布局与缩放、关闭和卸载表现仍需完整游戏内验收。其他区服尚未验证；游戏或 Dalamud 大版本更新后，请以插件管理器中的兼容状态为准。

若同时使用 Allagan Market，请关闭其物品和雇员高亮，避免冲突。普通用户通过插件管理器安装即可，无需自行编译。源码构建和检查说明见[开发文档](docs/development.md)。
